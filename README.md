## 🚀 怎么用

### 📱 手机推荐用法

1. Finder 里右键 `app.html` → **共享 → AirDrop → iPhone**
2. iPhone 收到后点开 → 分享 ⤴️ → **添加到主屏幕**
3. 桌面出现 🥢 图标

**用法**：
- 点 **「抽一套！」** → 看今天吃啥（主菜+汤+主食，自动应用偏好 + 自催化学习）
- 点 **「🍱 三餐」** → 抽出早+午+晚一整天的安排 + 营养均衡检查
- 点 **「冰箱有什么」** → 输入食材 → 看能做啥
- 点顶部 **「⚙️ 偏好设置」** → 自定义菜系/口味/忌口/时间，抽菜时自动避开；**看"我学到了什么"面板**
- 点顶部 **「📝 手动记录」** → 吃完直接输入吃了啥 → 自动写进历史和评分
- 抽菜结果旁边的 👍👎✅ 三个按钮 → 表达喜欢/不喜欢/做了 → 系统学得越来越准
- **点任意菜名** → 弹出菜谱（食材/调料/做法/小贴士）

### 💻 桌面端 / 命令行

**单餐随机套餐**：
```bash
cd /Users/deqin/Documents/2026-08-1_study/what-to-eat
python3 what_to_eat.py
# 输出：🍖 主菜 / 🍲 汤 / 🍚 主食 + 30 天不重复
```

**一日三餐**：
```bash
python3 what_to_eat.py --three-meals
# 输出：☀️ 早餐 / 🌞 午餐(主菜+主食+凉菜+汤) / 🌙 晚餐(主菜+主食+凉菜)
#       + 营养覆盖：✅ 蛋白  ✅ 碳水  ✅ 蔬菜
```

**应用偏好**：
```bash
# 只要川菜 + 不辣 + 30分钟内
python3 what_to_eat.py --prefs '{"cuisines":["川菜"],"spicy":"none","maxTime":30}'

# 一日三餐 + 不要海鲜
python3 what_to_eat.py --three-meals --prefs '{"avoid":{"seafood":true}}'
```

**记录评分（自催化学习）**：
```bash
python3 what_to_eat.py --like "清炒时蔬"
python3 what_to_eat.py --dislike "麻婆豆腐"
python3 what_to_eat.py --cooked "红烧肉"
# 记录后所有抽菜都会按这些评分加权推荐
```

**手动记录今天吃了啥**：
```bash
# 单餐或多菜都用逗号分隔
python3 what_to_eat.py --log '{"date":"2026-08-15","meals":{"早餐":"小米粥, 鸡蛋","午餐":"米饭, 红烧肉","晚餐":"面条"}}'
# 不写 date 默认今天

```
每条记录自动：① 进历史（下次抽签 30 天/7 天会避开）② 自催化评分 cooks +1

**按食材筛选**：
```bash

```

直接双击 `app.html`，或者：

## ⚙️ 偏好设置（Day 10）

手机端：顶部 → **⚙️ 偏好设置** → 勾选 → 保存

**五个分类**：
| 分类 | 选项 |
|------|------|
| 🍜 菜系（多选） | 川菜、东北菜、家常（数据里有的） |
| 🌶️ 口味 | 辣度（不辣 / 微辣也行 / 随便）、不要麻辣 |
| 🍽️ 忌口（多选） | 海鲜、内脏、香菜、牛肉、羊肉、皮蛋 |
| ⏱️ 烹饪时间 | 不限 / ≤30 分钟 / ≤60 分钟 |
| 🥗 其他 | 素食、不要凉菜、不抽早饭 |

**说明**：
- 全部不勾 = 不过滤（与旧版行为一致）
- 偏好存在 iPhone 本地（localStorage key: `what-to-eat-prefs`）
- 极端组合过滤后空 → 自动回退到原列表（不会抽不到）

**菜系数据缺口**：当前 86 道菜里只有 14 道打了菜系标签（川菜 12 + 东北菜 2 + 家常 20 部分）。菜系筛选的"川菜"实际是 12 道范围内抽。后续告诉 Claude"哪些菜是哪个菜系"可补全。

## 🧠 自催化学习模型（Day 11）

**让 app 越用越懂你口味**。每道抽出的菜右边有 3 个反馈按钮：

| 按钮 | 含义 | 权重影响 |
|------|------|---------|
| 👍 喜欢 | 显式点赞 | 该菜 +3 |
| 👎 不喜欢 | 显式点踩 | 该菜 -5（强烈降权） |
| ✅ 做了 | 真做了这菜 | 该菜 +2（隐式喜欢） |

**Tag 推断**：点赞/做了 麻婆豆腐 后，系统也会**自动推断你偏好川菜**（亲和度归一到 -1 ~ +1），下次抽菜同川菜概率↑。点踩红烧肉后推断你不喜欢「家常」类，下次推荐回避。

**算法公式**：
```
weight(dish) = 1.0                          # 基础
             + likes × 3                      # 喜欢 ↑
             + cooks × 2                      # 做了 ↑
             - dislikes × 5                   # 不喜欢 ↓↓
             + Σ tag_affinity[t] × 4         # tag 推断扩散
```

**手机端使用**：
- 抽菜结果右边点 👍/👎/✅ → 弹"已记住"提示，状态立刻反映
- 进 **⚙️ 偏好设置** → 滚到底部 → **"📊 我学到了什么"** 面板：
  - 已学 X 道菜
  - 你喜欢的（Top 3）/ 不喜欢的（Top 3）
  - 我推断你偏好：川菜 +60% / 辣 -40% 等
- 面板底部 → **"重置所有评分"** 一键清零

**CLI 用法**：
```bash
python3 what_to_eat.py --like "清炒时蔬"
python3 what_to_eat.py --dislike "麻婆豆腐"
python3 what_to_eat.py --cooked "红烧肉"
# 之后所有抽菜都按评分加权推荐
```

**隐私**：
- 评分存在 iPhone 本地（`localStorage['what-to-eat-scores']`）
- 不上传服务器
- 卸载 app / 清 Safari 数据 = 评分清零

**冷启动**：没有评分时 = 均匀随机（与 Day 10 一致）。需要 3+ 次交互才开始推断 tag。

## 📝 手动记录（Day 12）

不抽签也能记。**适合"今天吃了外卖/剩饭/孩子想吃的"**——只要记一次，下次的抽签就会避开。

**手机端使用**：
- 顶部 → **📝 手动记录** → 弹窗
- 选日期（默认今天）→ 三餐输入框填菜名
- 多个菜用 **逗号分隔**（如 `米饭, 红烧肉, 紫菜蛋花汤`）
- 点 **保存记录** → 自动写进历史 + 自催化评分（cooks +1）

**记录本**（点保存旁的"📋 查看记录本"）：
- 按日期分组
- 每条标注：🍱 抽签 / 📝 手动 / ⏭️ 跳过
- 显示对应餐次 ☀️/🌞/🌙

**数据流向**：
```
手动记录 → history.json（status='manual', 带 meal 字段）
         → scores.json（每菜 cooks +1）
下次抽签时 → 30 天/7 天不重复会避开这些菜
         → 自催化权重微微推高这些菜
```

**纯自由文本**：你可以输入任何名字——比如 `张三做的红烧肉`、`外卖`、`剩菜`。如果名字刚好匹配 `dishes.json` 里的 86 道菜，自动参与去重；纯自定义名字只做记录，不去重。

## ⚠️ 关于菜谱内容

**菜谱来自通用中餐知识**，可能跟你家做法不完全一样。**强烈建议你按自己口味改**：

1. 用 TextEdit 打开 `app.html`（先 `格式 → 制作纯文本`）
2. 找到要改的菜，比如搜索 `"红烧肉"`
3. 改 `steps:` / `seasonings:` / `tip:` 这三块的引号内文字
4. 保存，重新打开

> 比如把"加冰糖"改成"加红糖"、把"煮 10 分钟"改成"煮 20 分钟"，都是改个数字的事。
