# ADR-005: 极简 UI 纪律（带孩子场景）

**日期**：2026-08-23
**状态**：Accepted

## Context

JTBD 调研 #5：用户带孩子时**不想让孩子看到手机**。

意味着孩子如果看到手机屏幕：
- 不应被**吸引**（不会凑过来要玩）
- 不应让用户**拿手机太久**（孩子会注意到）

## Decision

**所有 UI 必须遵守以下纪律**：

### ❌ 不要
| 类别 | 反例 |
|---|---|
| **动画** | 弹跳、缩放、旋转 loading、过渡淡入 |
| **鲜艳色** | 大红、大绿、彩虹、紫粉渐变 |
| **emoji 滥用** | 标题/正文里大量 emoji，**只在 chip 行适度使用** |
| **声音** | 提示音、震动反馈 |
| **夸张文案** | 「恭喜！」「太棒了！」「耶！」|
| **loading spinner** | 旋转动画（统一用「加载中…」文字）|

### ✅ 用
| 类别 | 正例 |
|---|---|
| **低饱和配色** | 米色 `#fafaf7`、灰白 `#f5f5f5`、单一品牌色 `#ff9a3c` |
| **静态文字反馈** | 「加载中…」「已记录 ✓」|
| **极简 emoji** | chip 行小图标（1 个/行），不在正文滥用 |
| **静默成功** | toast 1.5 秒自动消失，无声音 |
| **中性文案** | 「已加」「已记录」「删失败」|

## Consequences

**✅ 好的影响**
- 适配核心使用场景（带孩子）
- 加载快（无动画 = 无渲染开销）
- 视觉风格统一（不浮夸）
- 用户**省心**：不被多余反馈干扰决策

**❌ 代价**
- 视觉上**不如其他工具「好看」**（牺牲美观换实用）
- 没有动画反馈，**新用户上手可能不直观**
- 不适合「炫耀性使用」（不能发朋友圈说「看我用了一个超酷的工具」）

## 不可逆性

**部分不可逆**。一旦用户习惯了极简 UI，加回去动画/颜色需要重新做用户教育。但因为是**逐步上线**，可以小范围测试。

## 验证指标

- 用户在饭点停留时间 < 30 秒（说明「快速 + 不用动脑」目标达成）
- 公开测试用户反馈「是否注意到孩子被吸引过」（负面反馈应 < 10%）
